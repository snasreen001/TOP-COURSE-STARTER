<h1>Top Course Starter</h1>
Link - https://snasreen001.github.io/TOP-COURSE-STARTER/ <br><br>
<div>Top Course Starter is a frontend application built using React.js that displays a collection of courses categorized into different domains. Users can filter courses by selecting specific categories from the filter section.</div>

<h3>Features</h3>
<ul>
  <li>Displays a heading "Top Courses"</li>
  <li>Filter section with buttons: <b>All, Development, Business, Design, Lifecycle</b></li>
  <li>Cards section displaying all courses initially</li>
  <li>Clicking on a category button filters the courses based on the selected domain</li>
</ul>

<h3>Technologies Used</h3>
<li>ReactJS</li>

<h3>Installation & Setup</h3>
<ol>
  <li>Clone the repository: <b>git clone https://github.com/snasreen001/TOP-COURSE-STARTER.git</b></li>
  <li>Navigate to the project directory: <b>cd top-course-starter</b></li>
  <li>Install dependencies: <b>npm install</b></li>
  <li>Start the development server: <b>npm start</b></li>
</ol>
